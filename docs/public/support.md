# Support and feedback

For ordinary feedback, feature requests, missing-provider requests, native-shell bugs, and non-sensitive packaging issues, use the [AI Drawer Microsoft Form](https://forms.cloud.microsoft/r/WLQySVad7g).

Do not include prompts, responses, provider page content, full sensitive URLs, account identifiers, credentials, cookies, tokens, payment data, DOM captures, or network traces. AI Drawer does not need provider account content to investigate native-shell defects.

Provider compatibility evidence may use the repository's bounded provider-evidence issue template when the report contains no sensitive information.

Suspected vulnerabilities must use [GitHub Private Vulnerability Reporting](https://github.com/Sumire-no-kai/AI_Drawer/security/advisories/new), not the ordinary feedback form or a public issue.

Optional donations may be made through [Edward Lee's shared Buy Me a Coffee page](https://buymeacoffee.com/edward_lee). Donations support independent projects and do not activate AI Drawer, provider services, subscriptions, accounts, premium features, priority handling, or a technical-support contract.
