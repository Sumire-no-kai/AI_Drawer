# AI Drawer

AI Drawer is a lightweight, privacy-respecting Windows workspace for official AI web applications you already use.

It provides one native window, global shortcut, tray workflow, and bounded set of WebView2 workspaces. Providers continue to own authentication, conversations, history, subscriptions, billing, uploads, and downloads.

AI Drawer is independent and unofficial. It is not affiliated with, endorsed by, sponsored by, or supported by any listed AI provider.

## Privacy boundary

AI Drawer does not read or store prompts, responses, page DOM, credentials, cookies, tokens, payment data, uploaded-file contents, or provider conversation content. Provider site data is stored by WebView2 in an AI Drawer-specific local profile so sign-in can persist separately from the user's normal Edge or Chrome profile.

## Purchase boundary

AI Drawer does not sell or process AI subscriptions. Known billing, checkout, subscription, and payment routes are blocked inside the application on a best-effort basis. Use Edge, Chrome, or another browser you trust when purchasing or managing a provider subscription.

## Current release state

There is no supported public download yet. Provider and platform status will be published only after the matching release Gate passes.
