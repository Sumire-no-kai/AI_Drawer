# Download AI Drawer

AI Drawer does not currently have a supported public build. Do not redistribute unsigned internal candidates from development artifacts or GitHub Actions.

When a Public Beta is approved, this page will link to the exact GitHub prerelease rather than host an independent copy. Every release entry must provide:

- the release version, source commit, and signed tag;
- architecture-specific signed packages;
- SHA-256 checksums;
- signing identity and verification instructions;
- verified Windows and architecture coverage;
- release notes and known limitations;
- installation, update, rollback, and uninstall guidance.

The stable channel is planned to use Microsoft Store MSIX distribution. A GitHub package is a secondary distribution route, not permission to ignore Windows signing warnings.
